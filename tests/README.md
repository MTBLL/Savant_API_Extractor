# Savant API Extractor Tests

This directory contains tests for the Savant API Extractor.

## Running Tests

To run all tests:

```bash
uv run pytest
```

To run with coverage report:

```bash
uv run pytest --cov=fangraphs_api_extractor --cov-report=term-missing
```
